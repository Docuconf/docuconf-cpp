All notable changes to docuconf-cpp are documented here. Entries after 0.1.0 are generated by
[release-please](https://github.com/googleapis/release-please) from Conventional Commit messages; see
[CONTRIBUTING.md](CONTRIBUTING.md).

## 0.1.0

First version: typed configuration contracts for [CLI11](https://github.com/CLIUtils/CLI11), implementing spec
`v1alpha1`.

### Features

* Declaration API on CLI11 options: descriptions, secrets, constraints, enums, lists, durations, JSON values,
  URL schemes and deprecations.
* File inputs: TLS key pairs, CA bundles, PKCS#12 and JKS keystores, JSON/YAML/TOML config files, text and binary
  files, all checked at boot.
* Boot validation that reports every violation at once with stable error codes.
* Export of the declaration as `contract.cue` (`--docuconf-export`), contract-first mode, and the shared
  conformance runner.
* The `orders` example service, CMake packaging (`find_package(docuconf)`, `FetchContent`) and CI.
